    1. Все машины марки Toyota:

    toyota_cars = Car.objects.filter(brand="Toyota")
for car in toyota_cars:
    print(car)

    Результат

    Toyota Corolla (ABC101)
Toyota Camry (ABC404)

    2. Владельцы, чьи имена содержат "Svetlana":

    svetlana_owners = CarOwner.objects.filter(first_name__icontains="Svetlana")
for owner in svetlana_owners:
    print(owner)

    Результат

    Svetlana Kuznetsova

    3. Случайный автомобиль и его владелец:

    import random
random_car = random.choice(list(Car.objects.all()))
owner = random_car.owners.first()
print(f"{random_car} - {owner}")

    Результат

    Nissan Altima - Ivan Sidorov

    4. Все владельцы машин черного цвета:

    black_cars = Car.objects.filter(color="Black")
black_car_owners = CarOwner.objects.filter(ownership__car__in=black_cars).distinct()
for owner in black_car_owners:
    print(owner)

    Результат

    Задание 3

    Описание

    Использовать аннотации и сортировки для анализа данных.

    1. Самая ранняя дата начала владения машиной:

    print(Ownership.objects.earliest('start_date').start_date)

    Результат

    2024-01-15

    2. Количество машин у каждого владельца:

    from django.db.models import Count

owners_with_car_count = CarOwner.objects.annotate(car_count=Count('ownerships__car'))
for owner in owners_with_car_count:
    print(f"{owner.first_name} {owner.last_name} - {owner.car_count}")

    Результат

    Alexey Voronin - 2
Natalia Petrova - 1
Ivan Sidorov - 1
Elena Fedorova - 1
Oleg Belov - 1
Svetlana Kuznetsova - 2

    3. Количество машин каждой марки:

    car_brand_counts = Car.objects.values('brand').annotate(count=Count('brand'))
for brand_count in car_brand_counts:
    print(f"{brand_count['brand']}: {brand_count['count']}")

    Результат

    Toyota: 2
Honda: 1
Nissan: 1
Hyundai: 1

    4. Сортировка владельцев по дате выдачи удостоверения:

    sorted_owners_by_license_date = CarOwner.objects.filter(driverlicense__isnull=False).order_by('driverlicense__issue_date')
for owner in sorted_owners_by_license_date:
    license_date = owner.driverlicense_set.first().issue_date
    print(f"{owner.first_name} {owner.last_name} - {license_date}")
